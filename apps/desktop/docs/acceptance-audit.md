## 1. 本轮结论

后续交互减负复核：已移除已消费消息回执、继续按钮及自动填词、agent 就绪历史提示、输入框动作副标题及空置顶教学。等待／失败状态仍保留。扩展会话回归、17 项 i18n 测试、类型检查及生产侧栏／第二进程重启通过；详见 [交互检查记录](interaction-review.md)。418 项全量记录属于此前运行，本次没有将定向复验冒充新一轮全量结果。

新侧栏、手动置顶、重命名、归档／恢复／永久删除已实现。静态检查及 CDP 生产集成通过；关闭到托盘的生产回归通过。操作系统托盘及通知的真实点击仍待人工填写，不标为产品全平台验收通过。

本轮发现并修复两项实际缺陷：SDK 普通枚举按当前 cwd 过滤，导致其他项目重启后不可见；归档的迟到回执可能覆盖用户随后打开归档页的选择。前者改用完整模式目录枚举并保留归属校验，后者增加用户交互版本校验，均有生产回归。

自动化原始记录：[418 项单测](navigation-evidence/unit-tests.txt)、[源码边界与类型检查](navigation-evidence/static-checks.txt)、[CDP 及第二进程重启](navigation-evidence/cdp-and-restart.txt)。最终小范围修改后另执行 49 项导航／通知／首轮持久化／Agent／i18n 定向测试，全部通过。

## 2. 除新设计之外，旧方案还剩什么

| 项目 | 当前事实 | 尚需完成 |
| --- | --- | --- |
| Windows 托盘恢复（原 G7） | 原生 Tray／hide／退出协调代码存在；程序触发回调的自动回归通过 | 实际点击 × 后在系统托盘找回应用，确认窗口、会话和任务连续；不能用测试回调代替 |
| Windows 系统通知（原 G7） | 去重、偏好、通知对象与目标恢复有自动化证据 | 实际后台完成／需回应通知送达、不抢焦点；点击能恢复窗口并定位正确会话；新侧栏接入后重验 |
| 跨平台声明 | 当前有 Windows 部分系统输入记录，无 macOS 原生验收 | 若发布并宣称 macOS 同等体验，补该平台关闭／后台驻留／恢复／通知验证；不能外推 Windows 结果 |
| 最终证据收口（原 G8） | 文档现已统一，旧三选一和旧活动区已退出当前要求 | 自动化证据已收口；收到人工表单后追加原生结果，保持静态／CDP 与物理交互的范围分开 |

另有一项原架构手段尚未实现：**按会话裁剪后台正文订阅**。当前后台事件统一送到 renderer，已有有界缓存、合并与通过的性能基准；它是可选优化，不是新的必做模块。新侧栏复测已通过原门槛；后续仅在实际性能问题出现时再决定是否实施。

没有证据支持“还缺一批底层模块”的说法；上述未验收项也不等于已经证实存在产品故障。

## 4. 新设计逐项验收

| 编号 | 范围 | 结果与证据 |
| --- | --- | --- |
| N1 | 跨模式目录摘要、置顶／标题／归档元数据、恢复和删除准入 | 已实现；存储原子替换失败不改内存，损坏文件禁止恢复执行；新进程验证跨项目数据仍完整 |
| N2 | 上置顶下项目、折叠、行内状态、右键／⋯菜单、移除旧活动区 | CDP 鼠标点击通过；同名不同目录不合并，置顶只有一份，流式完成不重排；跨模式打开正确 |
| N3 | 只读归档页、撤销、恢复、永久删除与迟到导航 | CDP 通过；运行／停止中归档被拒绝；归档不能通过 IPC 提交；恢复保留草稿；删除有确认且项目文件保留；延迟归档响应不覆盖新选择 |
| N3 持久性 | 完整退出后第二进程启动 | 已通过，恢复置顶、归档、标题、目录、折叠和草稿；没有新增模型请求。原目录缺失时恢复仍保留归属，提交返回 PROJECT_UNAVAILABLE，不调用模型或重建目录 |
| N3 通知目标 | 归档项打开只读历史，已删除项说明已删除 | 会话打开路径复用只读归档；确认删除后的迟到通知有独立单测，不会选中其他会话 |
| N4 静态／CDP | 源码边界、类型、实际页面、多尺寸／分屏及性能 | 已通过。CDP 截图见 [navigation-evidence](navigation-evidence/README.md)，受控布局详见 [layout-evidence](layout-evidence/README.md) |

另已重跑并通过：`smoke-production-main.mjs`、`smoke-production-navigation.mjs`、`smoke-production-context.mjs`、`smoke-production-metadata.mjs`、`smoke-production-deletion.mjs`、`smoke-tray-lifecycle.mjs`、`smoke-activity.mjs`、`smoke-conversations.mjs`、`smoke-history.mjs`、`review-layout.mjs`。旧删除测试已改成“拒绝活动归档／删除 → 显式停止 → 归档 → 确认删除”，不再要求旧交互存在。

测试使用独立临时 userData、假模型端点和测试目录。未操作用户真实会话或 Foundry 世界，未发布安装包。
