# 侧栏：置顶与项目

2026-09-07。依据用户提供的 Kimi Code Web 截图及本次说明。这是替换现有“活动 + 会话”导航的设计记录，界面尚未改造；原 goal 不自动恢复。

## 用户确定的结构

同一个左侧栏分为上下两个区域：上面手动置顶，下面按照项目（工作文件夹）聚合会话。运行中仅在会话行末尾显示小转圈，不需要独立活动列表或顶部运行数横栏。

```text
新建会话

置顶
  今晚的冒险素材                ◌
  上周战斗记录

项目
  ▾ 龙之谷
      整理 NPC 资料            ◌
      城镇地图
  ▸ 海上冒险
  ▸ 默认工作区
```

图中的 ◌ 代表运行中的转圈。两区属于同一个导航栏，不是额外增加一列面板。右侧对话和 Foundry 面板仍按现有空间布局。

## 补齐的交互细节

- 置顶是用户主动选择；会话行的菜单提供“置顶/取消置顶”，不因为任务开始、结束或未读自动置顶。置顶记录重启后保留。
- 同一会话只出现一次。置顶后从项目内的普通会话列表移出，取消置顶回到原项目。置顶项可用次要文字显示项目名，完整路径放在悬停提示中。
- 项目按规范化的完整工作目录识别，文件夹名只用于展示。同名但不同路径的目录不能合并，必要时补父目录区分。真实工作目录为空的历史记录收进“未指定目录”，不臆造关联。
- 项目可折叠，展开状态保留。打开会话时定位并展开所属项目；新建会话沿用明确选中的项目目录。目录下的新建入口在该目录创建会话，不能悄悄使用另一个项目。
- 导航按项目组织，备团/战斗仍是会话自身属性。打开会话自动切到所属模式，不要求用户先切模式才能找到它。
- 行内采用单行标题、紧凑间距和固定宽度状态位。删除“任务进行中”占一整行的副标题；时间可作为弱信息，过程详情留在对话区。沿用 ArcaneDesk 现有字体和主题色，不照搬 Kimi 的品牌视觉。
- 运行状态只更新小转圈，不移动行、不新增副本、不自动展开其他项目。项目收起时可在项目行显示一个聚合转圈，避免后台任务完全不可见。
- 完成后停止转圈。需要用户回应时不继续转圈伪装成自动运行；在同一状态位用静态提示标记，详情点开会话查看。未读保留小点，不再增加活动区。此处是状态细节建议，不要求扩展更多提示层级。
- 侧栏收起时保留普通侧栏展开按钮，移除“运行 N / 待处理 N”常驻横栏。普通进度不弹提示；失败或需要回应仍可以通过会话标记和既有通知机制发现。

## ArcaneDesk 改造边界

替换 renderer 的活动列表/平铺会话列表和顶部计数栏；补充目录元数据、置顶与折叠状态持久化。复用既有按会话的权威任务状态、导航校准、草稿恢复和通知去重，不让 UI 简化影响后台执行。

验收围绕可见行为：置顶/取消后仅一份会话；同目录聚合且同名目录不误并；跨模式打开正确；转圈随真实状态开始/停止且不重排；折叠、草稿、阅读位置和置顶在切换/重启后恢复。
