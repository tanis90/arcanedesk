# 本轮桌面交互验收表

使用本次源码启动的 ArcaneDesk，旧窗口不会自动加载新代码。结束不需要保留的测试任务后，从托盘退出旧窗口，再在仓库根目录执行 `npm start --workspace apps/desktop`。本轮尚未发布安装包。

下面是留给真实桌面点击、缩放和手感的检查；对应逻辑已通过自动化。无需提供密码或修改真实模型密钥。

| 项目 | 操作步骤 | 应看到的结果 | 结果 |
| --- | --- | --- | --- |
| 归档与撤销 | 新建一个空测试会话，右键归档；移开鼠标等待约 5 秒。再归档另一个测试会话并点击撤销；也可用 Tab 将焦点放到撤销按钮并停留超过 5 秒 | 无确认框、无关闭 ×；提示自动消失，不抢输入焦点；撤销能恢复；焦点停留时按钮不会突然消失 | 待填 |
| 后台完成不打断 | A 发一个只读任务，立即切到 B 输入一段未发送草稿，等待 A 完成 | 顶部不出现通知横条，正文不被挤动；A 行显示未读；B 草稿和焦点不变 | 待填 |
| 新消息按钮和缩放 | 在有长历史的会话向上翻，等待新输出；将输入框输入多行，再拖动窗口宽度并打开 Foundry 分屏。可在实际 Windows 125%／150% 缩放下复核 | 只有一个向下入口；有未读时显示新进展；不盖住输入文字或发送按钮；点击到最新后清除未读 | 待填 |
| 切换会话 | 快速在两个有历史的会话间切换几次 | 已有内容立即出现；正常切换没有“正在更新进展”的小字闪烁；草稿和阅读位置保留 | 待填 |
| 错误详情 | 打开已有调用失败的会话，展开错误详情，再切走切回或重新打开应用 | 默认只显示简述；详情能展开看到原文；没有自动填写“继续”的提示词 | 待填 |
| Foundry 失败及恢复 | 使用一个已知无法连接的 Foundry 地址打开右侧；随后在对话中让 Agent 打开正确地址 | 左侧不出现加载提示或重置弹窗；失败仅在右侧；正确页面加载后失败提示消失。点击右侧页面仍能收起覆盖式侧栏 | 待填 |

以上只检查交互，不要求执行世界写入或安装模组。真实托盘点击和系统通知送达沿用原 [manual-acceptance.md](manual-acceptance.md)，本轮没有把它们标为已完成人工验收。
