在仓库根目录的终端执行：

```powershell
node apps/desktop/test/review-native-lifecycle.mjs --system
```

等待标题为 **ArcaneDesk — Native acceptance** 的独立窗口和终端 `READY system step 1`。窗口使用临时数据及本地受控模型，不需要填写 API Key，不使用你的真实会话，不操作 Foundry 世界。请在 Windows 通知设置中允许 ArcaneDesk 通知，并关闭本轮会阻止横幅的勿扰设置。若找不到图标，检查托盘的折叠区域。

W1–W3 按顺序在同一次运行中完成；整个流程约 2–5 分钟。测试最多等待每一步十分钟。遇到失败先记录现象和终端输出，不要启动第二份来覆盖结果。终端只有出现 `PASS native system: ...` 才算自动记录也通过。W4 是另一次普通应用检查，M1 仅适用于相应平台。
