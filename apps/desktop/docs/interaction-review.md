# 对话交互减负检查

2026-09-07。本文记录检查结果，不另立技术方案；现行规则已合入 architecture.md 和 spec.md。

检查范围：消息状态、任务终态、输入框、侧栏／归档、欢迎页、同步和历史恢复、停止／退出、Foundry 页面恢复、模型与语音设置、权限和删除确认。采用源码路径检查及受控 Electron 验证，不把代码检查写成所有真实场景的人工验收。

## 已修改

| 原行为 | 当前行为 |
| --- | --- |
| 每条消息永久显示“已交给助手处理／命令已处理” | 消费或处理完成后移除小字；等待和异常按实际状态展示，切换／刷新一致 |
| 发送失败和模型未消费输入混用状态 | 发送拒绝显示“发送失败”；执行侧未消费显示“未处理”；接收不确定不冒充失败 |
| 每轮结束向历史插入“agent 就绪” | 移除，结束状态由任务投影表达 |
| 停止／失败后的继续按钮、指导段落和长提示词 | 已删除；正常 abort 不另显示红色错误；不更改草稿 |
| 输入框常驻“开始新任务／补充当前任务” | 移除常驻文字，保留按钮悬停及无障碍动作标签 |
| 空置顶区教用户如何置顶 | 空区隐藏，置顶入口仍在右键及 ⋯ 菜单 |
| 同步提示暴露“缓存现场／执行侧校准”及常驻时间 | “正在更新进展”；最后确认时间保留在悬停详情；失败可重试 |
| 欢迎页解释“四态回执”和面板操作 | 简短介绍用途，保留主动点击的示例入口 |
| 归档、输入占位和通知文案重复解释操作或引用旧活动栏 | 精简文字，通知文案指向现有会话列表 |

## 保留的交互及理由

- 发送失败／接收不确定的重试：消息可能没有送达，幂等重试有实际作用。处理成功后清除入口。
- 停止中、资源等待、同步失败：说明为什么当前没有进展，不能静默伪装正常。
- 提问与审批：确有缺失信息或授权边界；普通聊天不额外加确认。
- 永久删除、删除模型配置、强制重建 Foundry 页面的确认：会删除数据、配置或停止占用页面的任务，保留具体后果。
- 归档撤销、恢复入口和只读状态：导航操作确实改变可编辑性；归档本身不确认。
- 权限、遥测、模型默认值与语音快捷键说明：帮助用户作出配置选择，区别于教用户如何聊天。
- 图片附件记录和工具执行详情：用于定位输入与操作结果；不把它们等同于成功回执。
- 用户主动点击的示例与斜杠补全：属于用户发起的输入辅助，不在停止或失败后自行填入。

## 验证

扩展 conversation-smoke：等待回执可见；consumed／handled 无小字；失败、取消、中断仍可识别；返回已消费历史不重新出现小字；重试清除入口；停止／中断不注入草稿。重启前测试显式等待 IndexedDB 写入，避免将未等待落盘的测试竞态误判为产品失败。

系统原生验收仍以 manual-acceptance.md 为准。本轮没有关闭用户正在验收的窗口，也没有改写其中已保存的草稿；已经被旧按钮填入的文字不擅自删除。
