# 狼人迁移题：冻结验收草案

题目：创建一个狼人，给它动作如潮，把它的武器里加上长弓。

用户未指定等级、版本或改造强度，允许本地已有的合法狼人来源，再满足两项增补要求。运行时仅追加唯一测试名称和“不修改已有角色”的隔离约束，不向模型提供资源位置、ID、次数公式或实现答案。两稿在查看迁移题资源前已经冻结，迁移失败不得回填指南后仍称未见测试。

本地只读预检：dnd5e.monsters 有 Werewolf；2014 automation 的 classfeatures 有动作如潮，basicweapons 有长弓。动作如潮源 uses.max 引用 @scale.fighter.action-surge，说明写明默认一次、短休或长休恢复。NPC 没有战士等级表时，模型需处理实际可用次数；只复制名称或留下无效引用不算完成。只修改新 NPC 的嵌入物品，不修改源包。

自动验收：唯一 NPC；基础六维、HP、类型、伤害免疫与所选狼人原有武器/特性机制保留；长弓为真实来源武器，有远程攻击并保留来源伤害（已有 NPC 专用长弓也可满足）；动作如潮为真实 feat，有活动、消费自身次数、实际可用一次、恢复配置。题目只说加入武器，不额外要求装备、弹药、上图、先攻或执行自动化。比较基础数据用于识别名为狼人但实际空白的卡；等价重建若不满足来源形态，需要人工复核，不能直接归因模型能力失败。

采用运行前快照作为来源参照，原始输出保留；源内容和目标分别读取。数据验收不证明变形或职业动作自动化执行，也不覆盖所有世界副作用。源包依赖缺陷只记录到 todo，不现场改包。具体测试结果维护在[唯一技术方案](foundry-prep-play-technical-plan.md#1420-通用需求核对-loop启动)。

首轮 draft1 的参照固定 2014，但题目没有指定版本；两稿都选 2024，故基础参照和长弓数量检查过严。原始结果保留，单列依据真实选用来源的只读复核，不算重跑。后续 draft2 在运行前保存 2014/2024 两个来源，按实际六维与 HP 匹配，再核对原有机制；不额外强制长弓恰好一件。其他来源或等价重建仍需人工复核。[首次迁移结果](prep-werewolf-transfer-results.json)。
