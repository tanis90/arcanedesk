## 全局走查

- **可跑通**：DM 视角从开场到结局过一遍，每章所需资产都能在世界内找到并打开
- **无重复**：合集已有内容只有引用件，无同名自建件
- **命名一致**：FVTT 内译名与资料库章节一致
- **版权边界**：模组全文只进本地世界，不导出、不发布、不进 Git
